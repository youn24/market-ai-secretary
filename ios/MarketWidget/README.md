# 市場ウォッチ（iPhone ウィジェットアプリ）

ホーム画面／ロック画面に、ウォッチリストの**値動きチャート**と**最新ニュース**を出すアプリ。
SwiftUI + WidgetKit + Swift Charts（iOS 17+）。

## ウィジェット
| サイズ | 中身 |
|---|---|
| 小 | 先頭銘柄の価格・前日比・チャート（点線＝前日終値） |
| 中 | 先頭銘柄のチャート ＋ ニュース3本（タップで記事へ） |
| 大 | 大きなチャート ＋ 他3銘柄のミニチャート ＋ ニュース3本 |
| ロック画面 | 矩形（価格＋チャート）／1行テキスト |

アプリ本体: 銘柄一覧・期間切替チャート（1日/5日/1か月/3か月）・ニュース・ウォッチリスト編集。
アプリを開いている間は60秒ごとに更新し、ウィジェットも即時更新する。

## ビルド手順（Mac）
```bash
brew install xcodegen
cd ios/MarketWidget
xcodegen            # MarketWidget.xcodeproj を生成
open MarketWidget.xcodeproj
```
1. 両ターゲット（`MarketWidget` / `MarketWidgetExtension`）の *Signing & Capabilities* で自分のTeamを選ぶ
2. バンドルIDは `com.youn24.*`。変えるなら `project.yml` の `bundleIdPrefix`・App Group と
   `Shared/Models.swift` の `groupID` を**3か所そろえて**直す
3. 実機を選んで Run → ホーム画面を長押し → 「＋」→「市場ウォッチ」

> App Group が使えない署名設定だと、ウォッチリストの共有が効かず**ウィジェットは既定の5銘柄**になる
> （アプリ側の編集がウィジェットに届かない）。クラッシュはしない。

## ⚠️ 「リアルタイム」の限界（正直に）
- **ウィジェットは真のリアルタイムにならない。** 更新はiOSが決める。15分ごとを要求しているが、
  1日の更新回数に予算（目安40〜70回）があり、遅れる・飛ぶことがある。数秒単位の更新は不可能。
  ウィジェット下部の時刻が「取得した時点」。
- チャートはタップで動かせない（ウィジェットの仕様）。操作できるのはアプリ側。
- 価格は Yahoo Finance の**非公式API**。無料データは最大15〜20分遅れ、取得制限や仕様変更で止まりうる。
  取れなかった日は古いキャッシュを「⚠︎ 古いデータ」付きで出す（新しく見せかけない）。
- 本格的にリアルタイムへ寄せるなら、サーバー（このリポジトリのActions等）から
  WidgetKitのプッシュ更新を送る方式が必要。APNs・Apple Developer Program（有料）が要る。

## 実装メモ
- 前日比は **range=1d の `chartPreviousClose` だけ**を前日終値に使う（5d/1yだと前日比が桁違いになる。CLAUDE.md 参照）。
  1日以外の期間は「期間の最初→最後」で変化率を出す。
- 色は本プロジェクトの規約どおり**上げ=緑・下げ=赤**（日本の慣習と逆）。
- ニュースは Google News RSS。題名末尾の「 - 配信元」は配信元と一致したときだけ削る。
- サンプルデータは**プレースホルダー専用**。取得失敗時に架空の数字は出さず「データを取得できません」を出す。
- ビルド確認用に `.github/workflows/ios_build.yml`（手動実行＋ios/変更時のみ・定期実行なし）。
